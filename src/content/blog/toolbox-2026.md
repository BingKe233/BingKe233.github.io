每年更新一次的工具清单。原则是：能一个工具解决的事，不用两个。

## 编辑器与终端

- **VS Code** —— 插件只留必要的那几个
- **Windows Terminal + PowerShell 7** —— 本机主力
- **Git** —— 版本控制，没得商量

## 开发环境

| 用途 | 选择 | 备注 |
| --- | --- | --- |
| 运行时 | Node.js | 前端生态的默认答案 |
| 包管理 | npm | 够用，不折腾 |
| 静态站点 | Astro | 就是本站 |
| 数据处理 | Python | 脚本和一次性任务 |

## 服务

- **域名**：一个 `.com`，长期持有
- **托管**：静态站点走 CDN
- **图床**：对象存储
- **邮件订阅**：暂时不用，RSS 足够

## 一个反直觉的结论

工具越多，切换成本越高。**今年唯一新增的工具是"删除"。** 砍掉了三个几乎不打开的订阅服务之后，效率反而提升了。

> 清单的意义不是列全，而是帮你确认：真正每天在用的，其实就那么几个。
